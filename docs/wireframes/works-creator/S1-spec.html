Works redesign wireframe

Annotations, assumptions, open questions

Numbers match the pins on the boards. Grayscale, low fidelity, placeholders only.

Annotations

  1. 1Site nav unchanged (existing SiteBar).
  2. 2Title and live count of items that match the current filters (existing).
  3. 3Search by title or client (existing). Combines with creator and sort. Stored as q in the URL.
  4. 4Creator chips: All, Pidge, Miuoni, chiseyi, Lomi, in the slot where Sort used to be (Sort is removed). Desktop: one row right of the search. Mobile: one scrolling row under the search with an edge fade. Active = filled + check, not colour. aria-pressed, 44px tall. Choosing a creator starts the profile transition (see Interaction).
  5. 5Section header with live count. Long-form keeps Vlogs / MVs / Normal Videos tabs; a group with no items loses its tab (existing).
  6. 6Card: 9:16 short-form, 16:9 long-form and thumbnails. Fixed-ratio box so nothing shifts. Duration badge and “Edit for @…” credit kept; thumbnails have no credit line (existing).
  7. 7Desktop hover or keyboard focus plays a muted 5s MP4 preview. Title is also in the accessible name and the viewer: nothing is hover-only.
  8. 8Back to all works. Returns to the default state; focus goes back to the chiseyi chip.
  9. 9Profile header: neutral grey avatar with initial, name, handle and bio placeholders. No external links unless verified.
  10. 10Stats: counts computed from portfolio items only. No followers, likes or views.
  11. 11Primary CTA “Start a project” links to Contact. No Follow button.
  12. 12Tabs: Short-form / Long-form / Thumbnails with counts. Search stays available. Arrow keys move between tabs.
  13. 13Grid: 3 columns on mobile and 6 on desktop for short-form; 16:9 tabs use 2 columns on mobile and 4 on desktop.
  14. 14Touch: first tap plays the preview in the card; the Open button (44px) opens the full video. Second tap on the card stops it.
  15. 15Empty tab: message plus two exits. Count shows 0.
  16. 16Short screen (667px tall): at 667px or less of height the header tightens (smaller avatar and gaps). Measured here: header, tabs, search/sort and the first full grid row end at 648px, so they fit in the first view.

Interaction and URL

  • URL: /works is All. Creator: /works?creator=chiseyi&tab=short&sort=newest&q=. Each filter change updates the URL (pushState); browser Back and Forward restore the state; a direct link renders the creator state on first paint.
  • Unknown creator id falls back to All.
  • “Back to all works” goes to /works and keeps q and sort.
  • Transition All → creator, about 1.5s, in this order: (1) the chip morphs into the profile avatar (pill → circle, label fades to the initial) while the other chips, the title and the old sections fade and slide out to the left; (2) the search bar eases down into the tabs row; (3) the profile details fade up, then the creator’s videos fade-slide up with an ease-out stagger. Back reverses it, and the old sections slide in from the right.
  • With prefers-reduced-motion: reduce: no morph or slides, an instant swap, no autoplaying previews. Only opacity and transform are animated except the morphing avatar; clicks are ignored while a transition runs.
  • Working version: the interactive prototype page (it uses #creator-chiseyi in the address because the preview frame only allows a hash).
  • Focus: on entering creator state focus moves to the name heading; on Back it returns to the chip. A polite live region announces “Showing chiseyi’s works”.
  • Media: posters (WebP, fixed ratio) load first; first row eager, the rest lazy. MP4 previews are not requested until hover, focus or tap; one preview at a time; stopped on leave, blur or tab change.

Accessibility

  • Touch targets 44px or more: chips, tabs, back, sort, search, CTA, Open.
  • Visible 3px focus outline on every control.
  • Search, sort and each icon-only control have labels; chip row is a labelled group; tabs use the tab pattern.
  • Active states use fill plus check or underline, not colour alone.
  • Info is never hover-only: title and credit are in captions (desktop), the accessible name and the viewer.
  • Text 12px or larger; grayscale text passes 4.5:1.
  • No sideways page scroll; only the mobile chip row scrolls inside its own box.

Assumptions

  • Latest approved direction is Poster C (OC palette), per the project doc dated 2026-11-15. This wireframe is grayscale; styling follows later.
  • Works becomes a grid page; the current paged sideways strips go away. Existing data-* hooks and filter scripts are kept in the build.
  • Creator labels follow your brief. The repo has Pidge, Chi and Miu, and no Lomi.
  • Stats come from clips.json and thumbnails.json at build time.
  • 16:9 tabs use 2 columns on mobile (3 columns would be about 115×65px). Confirm.
  • The creator chip row is hidden in creator state; switching creators goes through Back.
  • Placeholders everywhere for bios, handles, stats, links and descriptions.
