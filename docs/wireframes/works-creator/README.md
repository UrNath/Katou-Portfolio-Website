# Works page wireframe: creator profile state

Grayscale, low-fidelity, placeholders only. Static HTML boards; open any `*.html` file in a browser at the width in its name.
`gen.py` regenerates the boards (`python3 gen.py <outdir>`). Pins on the boards match the numbered list in `S1-spec.html`.
Not wired to the site; no production code changed.

`transition-prototype.html` is the clickable version of the All → creator transition (chip morphs into the avatar, search eases down, old content slides out, videos fade up; Back reverses it). It uses `#creator-<id>` in the address and respects `prefers-reduced-motion`.
